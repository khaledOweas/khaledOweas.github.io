About

An engineer, not a checklist of frameworks

I'm a Senior/Lead-level software engineer with more than ten years building, maintaining, modernizing, and optimizing software across enterprise and product environments. My strongest foundation is the .NET ecosystem — C#, ASP.NET Core, Web API, SQL Server, Entity Framework — complemented by deep frontend experience in Angular and, more recently, React with TypeScript.

My career spans healthcare, banking, insurance, government, manufacturing, and international software companies. More recently that's expanded into multi-tenant and multi-database architecture, application performance investigation, cloud troubleshooting, CI/CD pipelines with custom build agents, and dynamic reporting platforms.
